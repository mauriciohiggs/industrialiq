# Changelog

All notable public releases are documented in this file.

## Unreleased

### Added

- Added a live AI Mentor workspace with overview, readiness, study-plan, skill, and forecast views.
- Added competency, certification, career-readiness, and local progress intelligence with explainable coverage and confidence.
- Added Certification GPS with roadblocks, fastest and alternative routes, study-distance estimates, and planning forecasts.
- Added adaptive learning and diagnostic engines with tested recommendation and assessment APIs.
- Added a branching simulation framework with scenario validation, conditional decisions, scoring, competency impacts, and summaries.
- Added a local typed analytics boundary with bounded browser persistence and optional provider adaptation.
- Added deterministic local coaching and an optional strict-schema OpenAI-compatible coaching provider.
- Added the proposed PostgreSQL competency intelligence schema and engine documentation.
- Added the canonical `docs/` architecture, registry, knowledge graph, decisions, state, and roadmap set.

### Changed

- Connected saved practice and flashcard behavior to the Mentor dashboard and Certification GPS.
- Added mentor, course, module, flashcard, question, and exam learning events.
- Expanded the main navigation and hash-routed experience for mentor workflows.
- Updated progress/privacy documentation to describe local analytics and optional coaching.
- Updated the README to distinguish live systems, engine-only systems, planned services, and non-official readiness claims.

### Safety and limitations

- Readiness, career, GPS, and forecast values remain evidence-limited practice summaries, not official certification or employment outcomes.
- Adaptive, diagnostic, and simulation engines are tested foundations and are not connected to the learner UI in this release.
- The runtime graph is category-derived and uncurated; bundled questions do not yet contain explicit reviewed skill mappings.
- The database schema is not connected to a production backend.

## 1.0.0

- Released the IndustrialIQ Ignition Core learning track.
- Added original Ignition 8.1 practice questions, exams, flashcards, and progress analytics.
- Added local progress export, import, and reset controls.
- Added production deployment configuration for Vercel and GitHub Pages.
- Added continuous integration, security policy, and legal disclosures.
