# IndustrialIQ feedback

Feedback should be specific, reproducible, and safe to share publicly. Do not include credentials, personal data, industrial-system details, or sensitive network information.

## Where to send feedback

- [Share general user feedback](https://github.com/mauriciohiggs/industrialiq/issues/new?template=user-feedback.yml)
- [Report a bug](https://github.com/mauriciohiggs/industrialiq/issues/new?template=bug-report.yml)
- [Request a feature](https://github.com/mauriciohiggs/industrialiq/issues/new?template=feature-request.yml)
- [Request a course](https://github.com/mauriciohiggs/industrialiq/issues/new?template=course-request.yml)
- [Report a question](https://github.com/mauriciohiggs/industrialiq/issues/new?template=question-report.yml)

For a question report, include the question ID shown in the learning library and the reason the answer or explanation may be incorrect. Cite an official public reference when possible.

## What happens next

Maintainers will reproduce bugs, review evidence for question corrections, and look for repeated demand when prioritizing course and feature requests. Community response and learning impact matter more than raw vote count.

## Learning-data boundary

Progress remains local to the learner's browser. Unless a learner explicitly chooses to include a detail in a GitHub issue or approved study, the project does not collect learner-level progress, study history, or exported files.
