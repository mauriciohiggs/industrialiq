# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `main` branch.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for the repository. Do not open a public issue containing exploit details, personal data, credentials, or production-system information.

Include the affected version, impact, reproduction steps, and a safe proof of concept when possible. Maintainers will acknowledge reports as soon as practical and coordinate a fix and disclosure.

IndustrialIQ is a static, local-first learning application and does not provide production industrial-control functionality.
