# Certifications

Certification features build on the competency graph and local learning evidence.

- `gpsModels.ts` defines the certification navigation view model.
- `gpsPlanner.ts` ranks roadblocks, estimates remaining study hours, and creates route options.
- `gpsForecast.ts` projects readiness from the planned study pace without presenting it as a pass guarantee.
- `certificationGps.ts` connects progress data and competency intelligence to the GPS view.

The initial certification domain model remains in `../competencies/models.ts`.
